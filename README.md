# Product Catalog - Интернет-магазин на Laravel + Vue

Каталог товаров с админ-панелью, фильтрацией, поиском и корзиной (в процессе разработки).

## 🛠 Технологии

- **Backend:** Laravel 10/11, PHP 8.2+
- **Frontend:** Vue 3, Inertia.js, TailwindCSS
- **Database:** PostgreSQL 15
- **Web Server:** Nginx Alpine
- **Containerization:** Docker + Docker Compose
- **Asset Bundler:** Vite
